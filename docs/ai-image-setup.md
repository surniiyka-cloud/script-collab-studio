# ИИ-генерация кадров — включение и ограничения

**Состояние:** экспериментальная интеграция ComfyUI, отдельная от Yjs/сценария. Требуются установленный движок, совместимая модель и видеокарта. Код находится в PR #5, проверка сборки и генерации в Codespaces ещё не выполнена.

## Что сайт делает сам, а что нет

- «Создать текстовый план» — бесплатный детерминированный разбор сценария **без ИИ и без изображений**.
- «Улучшить план через ИИ» — предложит более кинематографические описания через Ollama **только после установки и настройки локальной модели**.
- «Сгенерировать изображение» — создаёт PNG 768×432 через локальный ComfyUI, прикрепляет к соответствующему утверждённому SHOT, не меняя реплики автора. Запрос выполняется только по нажатию пользователя. Нажимать отдельно на каждый нужный кадр.
- «Загрузить своё» — вручную прикрепить фото или звук.
- «Предпросмотр» — последовательность кадров со звуком; «Экспорт MP4» создаёт аниматик FFmpeg при наличии всех картинок. Не создаёт движение персонажей внутри кадра.
- **Важно:** картинки пока генерируются только по текстовому описанию SHOT. Загруженные фотографии персонажей не передаются в базовый workflow, идентичность лиц и постоянство костюмов **не гарантированы**. Для этого понадобится отдельный workflow с IP-Adapter/ControlNet и проверка лицензий.

## Настройка Ollama (не обязательна для картинок)

Установите Ollama на том же компьютере, где запущен API (или используйте безопасный приватный локальный туннель). Установите подходящую по возможностям компьютера модель. Проверка:

    ollama list
    curl http://127.0.0.1:11434/api/tags

Добавьте в **локальный непубликуемый** файл `apps/api/.env`:

    OLLAMA_URL=http://127.0.0.1:11434
    OLLAMA_MODEL=<точное_название_установленной_модели>

Остановите и перезапустите API. Если модель недоступна, блок «Покадровка и изображения» отобразит «Не подключён». Даже если сервер отвечает, выбранная модель может отсутствовать или не укладываться в ресурсы.

## Настройка ComfyUI — настоящая генерация PNG

1. Установите [ComfyUI](https://github.com/Comfy-Org/ComfyUI) **на машине с достаточной памятью/GPU**. Установите совместимый text-to-image checkpoint (совместимость с узлами `CheckpointLoaderSimple`, `CLIPTextEncode`, `KSampler`, `VAEDecode`, `SaveImage` обязательна). Выбирайте модель с подходящей лицензией.
2. Запустите ComfyUI **приватно**, не публикуя 8188 в интернет. Пример для локальной машины:

       python main.py --listen 127.0.0.1 --port 8188

3. Проверьте на **том же хосте, где работает Fastify API**:

       curl http://127.0.0.1:8188/system_stats

4. Добавьте в `apps/api/.env`:

       COMFYUI_URL=http://127.0.0.1:8188
       COMFYUI_CHECKPOINT=<точное_имя_файла_в_ComfyUI/models/checkpoints>

5. Перезапустите `pnpm dev`. В «Производство → Покадровка» увидите статус ComfyUI. У утверждённого кадра нажмите «Сгенерировать изображение». Генерация занимает ресурсы, может занять больше 110 секунд; текущая экспериментальная реализация выдаст ошибку ожидания, а не фальшивую картинку.

**GitHub Codespaces:** команды `localhost` внутри API относятся к удалённому Codespace, а **не к твоему домашнему Windows-компьютеру**. Простая локальная установка ComfyUI на Windows не подключит автоматически Codespaces. Для разработки можно запускать всё локально на компьютере с GPU либо создать защищённый SSH-туннель, который предоставляет нужный порт как 127.0.0.1 в окружении Codespaces. Не открывайте ComfyUI или Ollama в публичный интернет и не пересылайте API-ключи в Git.

Если движок отсутствует, все редакторские функции и ручная загрузка изображений продолжают работать, кнопка генерации недоступна. Публичный «неограниченно бесплатный ИИ» в эту версию не встроен.

## Технический протокол

API: `GET /api/v1/projects/:projectId/production/ai-status`; `POST /api/v1/projects/:projectId/production/shots/:shotId/generate-image`. Роль OWNER/EDITOR обязательна для генерации, состояния доступны только участникам проекта. Сервер использует фиксированный workflow без загрузки произвольных графов от пользователей, ComfyUI endpoint ограничен loopback, генерация ограничена двумя заданиями за 10 минут на IP, возвращаемые изображения валидируются как PNG до 8 МБ и сохраняются в приватное S3-хранилище.

Техническая основа — официальные эндпоинты ComfyUI `/prompt`, `/history/{prompt_id}`, `/view`. Запросы синхронные до 110 секунд и на первой версии не гарантируют восстановление результата после обрыва браузера. Для production нужны серверная очередь, Job IDs, retries и отмена, контроль GPU-затрат, аудиты, ограничение памяти и модель reference conditioning.

Документация: https://github.com/Comfy-Org/ComfyUI/blob/master/script_examples/websockets_api_example.py
